## サービス

業種と媒体を選び、広告文を貼ると、法令データベースと現場ルールに照らしたリスク診断と修正案を返す一次診断ツール。

## 対象とする規制領域

- 薬機法（医薬品医療機器等法）
- 景品表示法
- 医療広告ガイドライン
- あはき法・柔道整復師法の広告制限
- 健康増進法、食品表示・機能性表示制度
- 化粧品・医薬部外品の効能範囲、粧工連自主基準
- 獣医療法、ペットフード表示（動物・ペット業種）
- **CBD・カンナビノイド関連製品**（下記）

**この事業の強みは、違反の指摘ではなく代替表現・修正文案まで出すこと。** 診断の出力設計はこの前提に従う。

### CBD・カンナビノイド関連製品

**規制が最も大きく動くと見ている領域**として、事業領域に含める（2026-08-06 決定）。

関係する法令は薬機法だけで閉じない。少なくとも次が絡む。

| 法令 | 主な論点 |
|---|---|
| 大麻草の栽培の規制に関する法律 / 麻薬及び向精神薬取締法 | THCの取扱い、成分規制の枠組み |
| 薬機法 | 効能効果の標榜、未承認医薬品広告への該当性 |
| 食品衛生法・食品表示法 | 食品として流通する場合の表示 |
| 景品表示法 | 機能性・体感の訴求、根拠の実証 |
| 輸入手続 | 部位の証明、成分分析証明の要否 |

> **未確認（重要）**：改正法の施行時期、THCの残留限度値、輸入時に求められる書類の具体は、**一次情報での確認が済んでいない**。クライアント業務で用いる前に、厚生労働省・消費者庁・税関の公表資料で裏取りし、確認日を記録すること。本ファイルの記述は領域の枠取りであって、法令解釈の根拠ではない。

診断ツールへの組み込み（業種カテゴリの新設、法令マスターへのノード追加）は未着手。着手する場合は別RFCとして扱う。

## AIの位置づけ

法規上の判断をAIが最終決定しない。根拠・リスク・代替案を整理し、判断はまさに委ねる。UI上も「AIによる一次診断」であることを明示する。

## 技術構成

| 層 | 内容 |
|---|---|
| フレームワーク | Next.js（**Pages Router**） |
| ホスティング | Vercel（Hobbyプラン、Function Region `iad1`） |
| 利用枠・レート制限 | Upstash Redis（REST）。未設定時はプロセス内メモリへフォールバック |
| 決済 | Stripe（サブスクリプション＋請求ポータル） |
| AI | Anthropic Messages API。構造化出力（`output_config.format`）でJSONを保証 |
| データ | `data/rulebook_v2.json`（現場ルール）、`data/law_master.json`（法令マスター） |

仕様書で App Router 等が指定されていても、**稼働中のアプリは Pages Router**。移行は別RFC・別マイルストーンとして扱い、無断で行わない。

## ルール件数の扱い

対外に用いる件数は **773件＝広告表現チェックに使える現場ルールの件数** の1つだけ（2026-08-07 確定・D-007）。正本の総ルール数、重複を含む展開前の件数、過去の表記は使わない。

件数の出所は `data/stats.json` の `rule_count` で、これはビルドが算出する。**数字を手で書かない。**

## 情報の優先順位

矛盾したときは次の順で優先する。

1. まさの最新の明示的な指示
2. 現在の本番コードと実際の設定
3. GitHubの現在のブランチ・PR・コミット
4. Specification（存在すれば）
5. `CLAUDE.md`
6. 過去のRFC、README、会話記録
7. 推測

**推測で補わない。** 確認できないことは「未確認」と明記する。仕様と実装が食い違う場合、勝手にどちらも変えず差異を提示する。
