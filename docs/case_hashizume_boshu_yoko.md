# 事例1号：募集要項のひな形（動画のリンク先）

作成：2026-10-02／関連：`docs/case_hashizume_recruit_veo.md`、`docs/case_hashizume_recruit.md` §5

30秒の動画では労働条件を出し切れないため、「募集要項はプロフィールのリンクから」と案内する。そのリンク先がこのページになる。職業安定法は、求職者と最初に接触するまでに労働条件を明示することを求めているとされる。応募フォームや電話番号よりも前に、このページを読める並びにしておく。

`【】` の部分が未記入。父・母から聞き取って埋める。

## 募集要項（薬剤師）

| 項目 | 内容 | 書き方の注意 |
|---|---|---|
| 募集者 | 有限会社橋詰調剤 | 法人名を正式名称で |
| 職種 | 薬剤師 | |
| 業務内容 | 調剤、服薬指導、在宅訪問、医薬品の管理 【他にあれば追記】 | |
| 業務内容の変更の範囲 | 【例：会社の定める業務／変更なし】 | 2024年4月から必須。将来の配置転換まで含めて書く |
| 就業場所 | しみず薬局（高知県土佐清水市【番地】） | 住所まで |
| 就業場所の変更の範囲 | 【例：なかむら薬局（高知県四万十市）への異動あり／なし】 | 2024年4月から必須。2店舗あるので必ず決める |
| 雇用形態・契約期間 | 【正社員（期間の定めなし）／契約社員（○年、更新あり）など】 | 有期なら更新の上限の有無と、更新するかどうかの基準も書く（2024年4月から必須） |
| 試用期間 | 【有無・期間】 | 期間中の給与や条件が本採用と違うなら、両方を書く |
| 勤務時間 | 【始業○:○○〜終業○:○○】 | シフト制なら代表的な時間帯を複数 |
| 休憩 | 【○分】 | |
| 時間外労働 | 【有無・月平均○時間】 | |
| 休日 | 【週休○日（○曜・祝日）、年間休日○日】 | |
| 賃金 | 【月給○円〜○円】 | 幅を出すなら決まり方（経験年数など）を添える |
| 固定残業代 | 【有無】 | 有りなら ①固定残業代を除いた基本給 ②固定残業代の金額と相当する時間数 ③超えた分は追加で支払う旨、の3点を必ず書く |
| 手当 | 【通勤・住宅・資格など】 | |
| 昇給・賞与 | 【有無・前年実績】 | 実績のない数字は書かない |
| 社会保険・労働保険 | 【健康保険・厚生年金・雇用保険・労災保険】 | 加入するものを全部 |
| 受動喫煙防止措置 | 【屋内禁煙／敷地内禁煙など】 | 必須項目 |
| 応募方法 | 【電話・メール・フォーム】 | このページの一番下に置く |

## このページで使わない表現

| 避ける表現 | 理由 |
|---|---|
| 若手歓迎、20代活躍中、○歳まで | 年齢による選別を示す。原則禁止 |
| 女性薬剤師募集、主婦歓迎 | 性別による選別。薬剤師は例外職種に当たらない |
| 高収入、残業ほぼなし（実績がない場合） | 実態と違えば誤解を生じさせる表示になる |
| 別の薬局の写真、白衣のモデル写真 | 実際の職場と違うものを見せることになる。使うなら「イメージ」と明記 |
| 「アットホームな職場」だけで条件を書かない | 違法ではないが、明示義務を果たしたことにはならない |

## 父・母に送る聞き取り（下書き）

LINEでそのまま送れる形にしてある。送るかどうか、言い回しはまさが決める。

```
求人の動画とページを作っていて、条件を書くのに確認したいことがあります。
分かるところだけで大丈夫です。

1. 雇い方は正社員？ 契約社員？（契約なら何年で、更新するときの決め方）
2. 試用期間はある？ あれば何か月で、その間の給料は同じ？
3. しみず薬局で採用した人が、なかむら薬局に行くことはある？
4. 仕事は調剤・服薬指導・在宅以外に何かある？ 将来ほかの仕事を頼む可能性は？
5. 勤務時間（何時から何時）と休憩は何分？
6. 休みは何曜日？ 年間で何日くらい？
7. 残業は月にどれくらい？
8. 給料は月いくらから、いくらまで？ 残業代を最初から込みにしてる？
9. 手当（通勤・住宅・資格）は何がある？
10. 昇給とボーナスはある？ 去年の実績は？
11. 社会保険と雇用保険は入る？
12. 店の中は禁煙？
13. 応募はどこで受ける？（電話・メール・ハローワーク）
```

## 決まっていないこと

- このページをどこに置くか。候補は、ハローワークの求人票、Indeed、自前の1ページ（Instagramのプロフィールからリンク）。ハローワークに求人を出しているなら、その求人票を正としてリンクするのが手間が少ない
- 職業安定法の明示事項と明示のタイミング、固定残業代の書き方は二次情報を基にしている。公開前に厚生労働省の資料で照合する
