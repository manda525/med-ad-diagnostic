# 動画広告案件の運用設計（1人会社モデル）

作成：2026-09-06／Pharma-Ad Lab｜医療広告コンサル まさ（薬剤師）
対象：動画広告を受託業務のフレームへ加えるための、商品定義・工程・発注仕様・検収基準・単価設計。

---

## 1. 前提の置き方

動画を扱うということは、編集技術を身につけることではない。1人会社で複数案件を並行させる以上、編集作業そのものは外注に出す前提でなければ回らない。ここで握るべきは、外注に渡せない3つの層になる。

| 層 | 内容 | 外注可否 |
|---|---|---|
| 要件翻訳 | クライアントが言いたいことを、法令に耐える表現へ置き換える | 不可（まさの中核） |
| 発注仕様 | 外注編集者が判断で壊せないよう、確定稿と数値基準で縛る | 不可 |
| 検収 | 納品物のテロップ・音声・表示秒数を実測して照合する | 不可（一部は機械化可能） |
| 編集作業 | カット・テロップ載せ・書き出し | 外注 |

編集者は薬機法を知らないので判断させてはならず、逆に薬機法コンサルタントは動画の工程を知らないので仕様を書けない。この両方を持っていることが、この商品の成立条件になる。

## 2. 動画にしかない論点

文字広告のチェックでは構造的に検出できないものが3つある。法令マスターの `L-VIDEO-DISCLAIM` / `L-VIDEO-AUDIO` / `L-VIDEO-BA` に対応する。

第一に【表示時間】。打消し表示は入っていれば足りるのではなく、読み切れる秒数が出ていなければ意味がない。消費者庁の実態調査では動画広告の打消し表示は表示時間2秒以下が42.4%とされており（要一次確認）、業界の慣行そのものがリスク側に寄っている。裏を返せば、秒数を管理できる制作者はそれだけで差がつく。

第二に【音声】。広告該当性は誘引性と特定性で決まるので、ナレーションも出演者の発言も広告表現になる。テロップだけを点検して音声を見落とす事故が、動画案件では最も起きやすい。

第三に【編集による演出】。文言がすべて適正でも、ビフォー側だけ暗く撮る、アフター側にBGMの盛り上がりを足す、早送りで期間を圧縮する、といった編集で優良誤認のおそれが生まれる。これはテキストのチェックには絶対に現れない。

## 3. 標準工程

```
① 要件ヒアリング     クライアントが言いたいことの核を取る
② 台本作成・一次診断  薬機レーダーへ台本テキストを投入 → 修正 → 確定稿
③ 撮影              クライアント自前 or カメラマン外注
④ 編集発注          確定稿＋発注仕様書を渡す（§4）
⑤ 検収              テロップ・音声・秒数を実測照合（§5）
⑥ 納品・記録        工程の記録が次の営業資料になる
```

工程の重心は②にある。撮影後に表現を直すと再撮影の費用が発生するため、法務的な修正は必ず撮影前に終える。ここを外すと、動画は文字広告と違って修正コストが跳ね上がる。

## 4. 発注仕様書テンプレ（外注編集者へ渡す）

外注が良かれと思ってやることが事故になる。禁止事項を明示的に書く。

```
■ 案件名／尺／解像度／納期
■ 素材：撮影データ、確定稿（テロップ全文・ナレーション全文）

■ 絶対厳守（違反した納品は再修正）
1. テロップ文言は確定稿から一字も変更しない。
   キャッチーな言い換え・省略・語尾変更を含めて禁止。
   直したい箇所があれば編集を止めて発注者へ連絡する。
2. ナレーションは確定稿どおりに読む。アドリブ・言い換え禁止。
3. 注記（打消し表示）は最低◯秒間、本文と同一画面に表示する。
   文字サイズは本文の◯%以上、背景とのコントラストを確保する。
4. ビフォーアフターを含む場合、治療内容・費用・主なリスク副作用を
   同一画面または直後に最低◯秒間表示する。
5. PR表記は冒頭◯秒以内に、最低◯秒間表示する。
6. 以下の演出を禁止する。
   - ビフォーとアフターで色調補正・明るさ・彩度を変える
   - アフター側にのみBGMの盛り上がり、効果音、スローモーションを足す
   - 早送り・タイムラプスで期間を圧縮する（期間の明示がある場合を除く）
   - 白衣・聴診器・医療機関を想起させる素材を追加する
7. 素材の追加・差し替えは事前承認制。フリー素材も対象。

■ 納品物
- 完成動画（MP4）
- テロップ全文のテキスト書き起こし
- 注記の表示開始・終了タイムコード
```

数値（◯秒・◯%）は案件ごとに決める。表示秒数は「読み切れるか」で判断するため、文字数と読了速度から逆算する。

## 5. 検収チェックリスト

納品物を目視で流し見しても事故は見つからない。項目を固定して機械的に潰す。

| # | 確認項目 | 方法 | 落ちたときの影響 |
|---|---|---|---|
| 1 | テロップ全文が確定稿と一致 | 書き起こしテキストの差分 | 表現の逸脱＝薬機法・景表法 |
| 2 | ナレーションが確定稿と一致 | 音声の書き起こしを照合 | 同上。最頻の見落とし |
| 3 | 注記の表示秒数 | タイムコード実測 | 打消し表示の不備＝景表法 |
| 4 | 注記の文字サイズ・コントラスト | 画面キャプチャで確認 | 同上 |
| 5 | PR表記の有無・位置・秒数 | 冒頭からの位置を実測 | ステマ規制 |
| 6 | ビフォーアフター併記4項目 | 各項目の可読時間を実測 | 医療広告GL 限定解除不成立 |
| 7 | 体験談・インタビューの混入 | 全編確認（医療機関案件） | 医療広告GL 限定解除でも不可 |
| 8 | 演出による効果の誇張 | ビフォー／アフターの画づくり比較 | 優良誤認 |

3・5・6の表示秒数は目測ではなく実測する。この記録がそのまま、クライアントへ出す「なぜこの動画が安全か」の説明資料になる。

この検収のうち機械で判定できる部分は、コマンドとして実装済み。

```bash
npm run audit:video -- docs/case_hashizume_recruit_telops.json --video 納品.mp4
```

編集者から受け取ったテロップ表（JSON）を当てると、読了速度の超過、最低表示秒数の不足、打消し表示が強調表示と別カットになっていないか、PR表記が冒頭にあるか、必須項目の欠落、確定稿に残った仮テキストや求人NG表現を検出する。NGが1件でもあれば終了コード1を返すので、検収を通す条件をコマンドで固定できる。閾値は `lib/videoAudit.js` の `DEFAULT_THRESHOLDS` にあり、【行政が定めた基準値ではなく実務上の設計値】である点は変わらない。

| role | 読了速度の上限 | 最低表示秒数 | 用途 |
|---|---|---|---|
| body | 6.0字/秒 | 1.5秒 | 通常テロップ |
| legal | 5.0字/秒 | 4.0秒 | 法定明示・限定解除の併記事項 |
| disclaimer | 5.0字/秒 | 4.0秒 | 打消し表示。強調表示との同時表示も確認 |
| pr | 6.0字/秒 | 2.0秒 | ステマ規制のPR表記。冒頭3秒以内に初出 |

## 6. 単価設計

編集代行の価格帯では受けない。監修責任を負う以上、原価に工数とリスク引受を積む。

| 項目 | 金額 | 根拠 |
|---|---|---|
| 外注編集費 | 5,000円 | 市場の編集単価3,000〜8,000円の中央付近 |
| まさの工数 | 11,250円 | 要件翻訳＋台本診断＋仕様書＋検収で2.5時間、時間単価4,500円 |
| 原価計 | 16,250円 | |
| 提供価格（下限） | 40,000円／本 | 粗利率60%で逆算 |

月4本の継続契約なら月16万円。まさが手を動かすのは月10時間で、通勤と本業を抱えたままでも成立する。逆に自分で編集すると1本4〜6時間かかり、原価が2万円を超えて価格が崩れる。編集を持たないことが利益率の条件になる。

## 7. 事例作りの初手

最初の1本は橋詰調剤（実家）の求人動画を想定する。実クライアントで、公開許諾が取りやすく、応募数という数値が取れる。実家の課題である薬剤師不足にも直結する。この1本で §3〜§5 の工程を実際に通し、記録を残す。記録が残っていれば、次のクライアントには工程そのものを見せて売れる。

生成AI動画（Kling・Veo等）は、素材を用意できない案件の補完手段として位置づける。主軸は実写と工程管理に置く。

## 8. 未確認事項

- 消費者庁「打消し表示に関する実態調査報告書」の原文（表示時間2秒以下42.4%、動画広告の考え方の記述）は未読。作成環境から caa.go.jp へ到達できないため。
- 医薬品等適正広告基準における、テレビ・ラジオ等でのしばり表現の付記・付言の規定は未読。mhlw.go.jp へ到達できないため。
- 上記2点を確認するまで、`data/law_master.json` の L-VIDEO-* は `verified: false` のまま扱う。
- §4 の秒数・文字サイズの具体的な数値基準は、行政が一律の数値を示しているわけではない。案件ごとに文字数と読了速度から設定する。
