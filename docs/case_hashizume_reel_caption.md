# 事例1号リール：投稿文（Instagram・Facebook向け）

作成：2026-10-02／動画：`docs/case_hashizume_reel.json`

動画は31.5秒で、伝えられるのは雰囲気と入口まで。応募するかどうかは、本文と募集要項を読んで決めることになる。本文の役割は、迷っている人に「話を聞いてみよう」と思わせ、募集要項まで連れて行くこと。

## 本文案

```
足摺岬のまち、土佐清水で薬剤師を募集しています。

しみず薬局は、地域の方の処方せんを受け付ける調剤薬局です。
調剤や服薬指導に加えて、在宅訪問も行っています。
同じ方と長くお付き合いできるのが、この町の薬局ならではだと考えています。

勤務時間・給与・休日などの条件は、プロフィールのリンク先の募集要項にまとめています。
気になった方は、まずはそちらをご覧ください。

有限会社橋詰調剤（しみず薬局／なかむら薬局）

#薬剤師募集 #薬剤師求人 #高知県 #土佐清水市 #四万十市 #調剤薬局 #地方で働く #UターンIターン
```

## 書き方で気をつけたこと

| 点 | 理由 |
|---|---|
| 条件（給与・休日など）は本文に書かず、募集要項へ誘導した | 本文に一部だけ書くと、残りの明示事項が抜けたまま条件を示したことになる。条件は募集要項に一本化する |
| 「残業なし」「高収入」「アットホーム」を使っていない | 実態の裏付けがないまま書くと、誤解を生じさせる表示になる |
| 年齢・性別に触れていない | 「若手歓迎」なども含め、選別を示す表現は原則禁止 |
| 「〜と考えています」で結んだ | 事実として言い切れない雰囲気の話は、会社の考えとして書く |

## まさに確認してほしいこと

- しみず薬局で在宅訪問を実際に行っているか。行っていなければ、本文と動画の「在宅訪問」を外す
- 「同じ方と長くお付き合いできる」が実態に合っているか
- なかむら薬局でも募集しているか。していなければ本文の（　）からなかむら薬局を外し、ハッシュタグの「#四万十市」も外す
- 見学や「話を聞くだけ」を受け付けるか。受け付けるなら、最後に一文足すと応募の心理的な壁が下がる（例：「見学だけのご相談も受け付けています」）
